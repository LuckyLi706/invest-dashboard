# A股攻防板块趋势

纯静态站，托管在 GitHub Pages。

- **防御板块**：银行（中证银行指数 399986）、红利（中证红利指数 000922）、消费（中证主要消费指数 000932）
- **进攻板块**：通信（5G通信ETF 515050，跟踪中证5G通信主题指数）、半导体（半导体ETF 512480，跟踪中证全指半导体产品与设备指数）、芯片（国证芯片指数 980017）

## 数据

`data/data.json`：各标的近一年日线收盘价快照（`scripts/fetch_data.py` 生成，来源：新浪财经 / 腾讯证券公开行情接口）。
页面每次打开读取该快照渲染；更新数据只需重新跑脚本并重新部署。

## 本地预览

```bash
cd invest-dashboard
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署

推送到 GitHub 仓库后，在仓库 Settings → Pages 中选择从 `main` 分支根目录部署即可。
